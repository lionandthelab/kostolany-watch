## 2. P-DJ-1 — 헤드 불일치는 정보를 담는가

**대응 기능:** C1(출고됨, 사실 표시) → C9의 "불일치 조건부 적중률" 표기 허가 여부.

### 2.1 가설

> **H_DJ:** momo의 gold-side 적중률은 4개 헤드의 side가 만장일치인 봉에서,
> 갈린 봉보다 **높다.**

### 2.2 조건 변수와 비닝 (실행 전 동결)

* `n_side_agree(t)` = 4개 헤드(momo/hmm/gbm/tsfm)의 side 콜 중 momo의 side와
  같은 것의 개수 ∈ {1,2,3,4}. side는 `regime < 3`에서만 유도한다(확률 벡터 재계산 금지).
* **비닝은 이진으로 동결한다: `{4}` vs `{1,2,3}`.**
  왜 이진인가: 헤드가 4개뿐이라 4셀 비닝은 셀당 레그가 얇다. 4셀 분해는
  **보고 전용**이며 판정에 쓰지 않는다. 결과를 보고 비닝을 다시 긋는 것은
  selection에 의한 fitting이므로 금지(`confidence_spec §0.5` 계승).

### 2.3 지표와 판정 (실행 전 고정)

| | |
|---|---|
| 1차 | Δ_DJ = side_hit(agree=4) − side_hit(agree≤3), 층화 레그 부트스트랩, z=2.5758 |
| **채택** | Δ_DJ ≥ **+0.030** **그리고** CI가 0을 배제 → 「불일치 조건부 적중률」 표기 허가 |
| **미판정** | \|Δ_DJ\| < CI 반폭 → 미판정으로 보고. 표기 불가 |
| **기각** | 그 외 → **표기 영구 금지.** 불일치는 사실로만 표시한다(C1이 이미 그렇게 함) |

채택되더라도 표기는 **아티팩트 → `calibration.py` 전사 상수 → payload → `pctFloor`**
경로를 그대로 타야 한다(`confidence_spec §0.1` 단일 출처 원칙). 프론트 계산 금지.

### 2.4 킬 조건

| ID | 발화 | 결과 |
|---|---|---|
| **K-DJ-1** | 어느 셀이든 풀링 독립 레그 < **12** | 미판정. 표기 불가 |
| **K-DJ-2** | 두 시장의 Δ 부호가 반대 | 풀링 결과 인용 금지, 미판정 |
| **K-DJ-3** | 4헤드 OOS 콜 재생산에서 어느 헤드든 fold 실패 | 그 fold 제외 후 재실행이 아니라 **전체 미판정**(선택적 fold 제외는 사후 선택) |

### 2.5 실행 비용과 사전 경고

hmm/gbm/tsfm의 워크포워드 OOS 콜을 fold별로 재적합해 재생산해야 한다. 서빙 스택의
스냅샷이 아니라 하네스 재실행이며, 이 문서의 실험 중 가장 무겁다.

**선험 공시:** 4개 헤드는 서로 다른 입력을 쓰지만 **전부 같은 가격에서 파생된다.**
불일치가 side 스킬과 상관될 선험적 이유는 약하다. 이 실험은 그 약한 선험을
**반증하기 위해** 설계되었고, 기각이 기대되는 결과다. 기각되면 C1은 지금 모습
그대로 — 숫자 없는 사실 표시 — 로 영구히 남는다.

| J2 | `0.030` | 채택 임계 | `XS_BREADTH` §4의 ΔAUC +0.030 관례 계승. **측정 근거 없음** |

## 3. P-FLIP-1 — 전복 거리는 전환을 앞서는가

**대응 기능:** C3(출고됨, 산술 표시) → 「거리가 가까우면 전환이 잦았다」 문장의 허가 여부.

### 3.1 가설

> **H_FLIP:** 방향 전복 거리 `|side_flip.move_pct|`가 작은 봉에서, 이후 **10봉**
> 안에 실제 gold side 전환이 일어난 빈도가 더 높다.

10봉은 `labels_pit.confirm_lag = 10`(`labels_pit.py:32`)에서 상속한 값이며
새 자유 파라미터가 아니다.

### 3.2 조건 변수와 비닝 (실행 전 동결)

* 조건 변수 = `|side_flip.move_pct|`, 설계 문서 §5.1의 닫힌 형태로 매 봉 계산.
* 비닝 = **fold별 train 슬라이스에서만 잡은 삼분위.** 테스트 구간을 보고 자르는 것
  금지. `labels_pit.clock_terciles`(train 전용 삼분위) 관례를 그대로 상속한다.

### 3.3 지표와 판정 (실행 전 고정)

| | |
|---|---|
| 1차 | Δ_FLIP = P(10봉 내 side 전환 \| 하위 삼분위) − P(… \| 상위 삼분위) |
| **채택** | Δ_FLIP ≥ **+0.10** 그리고 CI가 0 배제 그리고 §3.4 카나리아 통과 |
| **기각** | 그 외 → 전복 거리는 **산술로만** 표시. 어떤 빈도 문장도 붙이지 않는다 |

### 3.4 셔플 카나리아 (필수 — `XS_BREADTH` §4 관례 상속)

조건 변수를 시간축으로 셔플한 팔의 Δ_shuffle CI가 Δ_causal을 **포함하면 기각.**
셔플이 인과와 구분 불가하다는 것은 이득이 배관 결함과 구분 불가하다는 뜻이다.

## 4. P-RUN-1 — 판정 지속 일수는 정보를 담는가

**대응 기능:** C4(출고됨, 카운트 표시) → 「오래된 판정이 더/덜 정확하다」의 허가 여부.

### 4.1 가설

> **H_RUN:** momo side 판정의 gold-side 적중률은 side run-length 셀에 따라 다르다.

### 4.2 비닝 (실행 전 동결)

**1–20봉 / 21–60봉 / 61봉+.** 경계는 `min_cycle = 60`과 그 1/3에서 유도했으나
**임의성이 있음을 공시한다.** 결과를 보고 경계를 옮기는 것은 금지.

### 4.3 위약 대조군 (이 실험의 핵심 — 생략 불가)

run-length는 gold 레그 길이와 **기계적으로 얽혀 있다.** 긴 레그는 정의상 긴 run을
낳고, 길이 편향 표집(length-biased sampling) 때문에 어떤 무정보 규칙이라도 긴 run
셀에서 더 높은 적중률을 낼 수 있다. 이 기계적 결합을 side 스킬로 오독하면 이 문서
전체가 무의미해진다.

> **위약 팔(P):** 같은 run-length 셀 구조를 유지한 채, side 콜을 **셀 안에서
> 무작위 치환**한 팔. 위약의 Δ_placebo가 0과 CI-구분 가능하면 **P-RUN-1 전체를
> 기각한다** — 관측된 Δ가 스킬이 아니라 표집 구조에서 나온 증거이기 때문이다.

### 4.4 지표와 판정 (실행 전 고정)

| | |
|---|---|
| 1차 | Δ_RUN = side_hit(최고 셀) − side_hit(최저 셀) |
| **채택** | Δ_RUN ≥ **+0.05** 그리고 CI 0 배제 그리고 셀 순서가 **단조** 그리고 §4.3 위약 통과 |
| **공시(채택 아님)** | 비단조 → 채택하지 않되 **정면 공개**한다(`confidence_spec §1`의 BTC 8-0 exact 비단조 공개 관례 상속) |
| **기각** | 그 외 → 지속 일수는 **카운트로만** 표시 |

### 4.5 킬 조건

| ID | 발화 | 결과 |
|---|---|---|
| **K-RUN-1** | 어느 셀이든 풀링 레그 < **12** | 미판정 |
| **K-RUN-2** | 위약 Δ가 0과 CI-구분 가능 | **기각** (§4.3) |

## 5. P-ANALOG-1 — 역사적 유사 국면 (오너 후보 「다」)

**기본값은 표시 금지다.** 아래 게이트를 **전부** 통과할 때만 표시가 허용된다.

### 5.1 왜 이 후보가 가장 위험한가

각 사실은 참인데 **선택이 주장을 만든다.** "지금과 가장 닮은 5일"을 고르는 행위
자체가 "이 5일이 지금과 관련 있다"는 미측정 주장이다. 이웃이 노이즈면 각 행이 참인
표가 통째로 오도한다. 따라서 이 실험은 "이후에 무슨 일이 있었나"를 재는 것이 아니라
**이웃 선택 자체가 정보를 담는가**를 잰다.

### 5.2 유사도 공간 (실행 전 동결)

**서빙 헤드가 보는 정보만 쓴다: 8규칙 투표 벡터(8차원 bool) + `log1p(clock k)`
1차원 = 총 9차원.** 거리 = 해밍(투표 8차원) + 표준화 절대차(시계 1차원), 가중
1:1 고정.

왜 이 공간인가: 서빙 헤드가 보지 않는 정보로 유사도를 정의하면 한 화면의 두 문장이
서로 다른 모델을 말하게 된다. 가격 수준·수익률 크기는 **넣지 않는다**(스케일 의존,
시장 간 비교 불가).

### 5.3 이웃 자격 (실행 전 동결)

이웃 후보 봉 `s`는 세 조건을 **전부** 만족해야 한다.

1. `s ≤ t − 252봉` (embargo). 인접 봉의 자기상관으로 자기 자신을 뽑는 것을 차단.
2. `s`가 속한 gold 레그가 **닫혀 있고**, 그 종료 전환점 이후 **40봉**
   (확정 지연 10 + 안정 버퍼 30, `LEDGER_SCORING_PREREG` §2.1 E1/E2 상속) 이상
   경과. 꼬리 전진채움 라벨을 이웃 사건으로 쓰지 않는다.
3. 같은 시장. **시장 간 이웃 금지**(빌린 테이블 금지 원칙의 확장).

### 5.4 표시 대상 (허가 시)

이웃 **N=5**개의 **날짜**와 그 뒤 실제로 일어난 **gold 레그 사건**
(전환까지 남은 봉 수, 전환 후 side). **확률·평균·수익률·가격은 표시하지 않는다.**
수익률을 넣는 순간 방향 예보가 되고 K7 위반이다.

## 6. P-COND-1 — 티어 × 지평 조건부 실현 분포 (오너 후보 「라」)

**대응 기능:** C8. 기존 `confidence_view.tiers[*].side_hit`의 **지평 축 확장**.

### 6.1 무엇을 재는가 — 그리고 무엇을 재지 않는가

* 재는 것: 티어 `T`인 봉 `t`에서, **`t+h`봉의 gold side가 `t`의 콜 side와 같았던
  빈도.** `h ∈ {10, 20, 60}` (동결).

> **정오표 (2026-08-07, 어떤 실행보다 앞섬).** 이 줄의 초안은 `{5, 20, 60}`이었다.
> 그것은 같은 항목의 근거(§6.5 J17 「`momo.RET_HORIZONS`와 동일 값을 재사용해 새 축을
> 만들지 않음」), §11의 상속 목록(`RET_HORIZONS={10,20,60}`), 그리고 코드
> (`momo.py:34` `RET_HORIZONS = (10, 20, 60)`) 셋 모두와 어긋난다. `5`는 오타이며,
> 그대로 두면 근거가 금지한 바로 그것 — 새 축 — 을 만든다. 셋과 일치하는 유일한
> 값으로 정정한다.
>
> 이 정정이 KJ7(사후 파라미터 변경)이 **아닌** 이유는 시점 하나다: 어떤 실험도 아직
> 실행되지 않았고 어떤 결과도 존재하지 않는다. 정정 방향은 결과가 아니라 코드가
> 정했다. 첫 실행 이후 같은 종류의 수정은 KJ7이다.
* **재지 않는 것: 전방 수익률·가격·변동성 분포.** 그것을 만드는 순간 방향 예보가
  되고 K7과 `confidence_spec §6 #3`을 정면으로 위반한다. 이 실험의 산출물에
  수익률 열이 존재하면 **그 산출물은 무효다.**

### 6.2 비닝 (실행 전 동결)

기존 4티어(8-0 / 7-1 / 6-2 / 분열)를 **그대로** 쓴다. 재비닝은
`confidence_spec §0.5`에서 금지된 fitting-by-selection이다.
지평 3개도 동결. 셀 = 4티어 × 3지평 × 2시장 = **24셀**.

### 6.3 표기 허가 조건 (셀 단위 — 전부 충족한 셀만)

1. 셀당 풀링이 아닌 **해당 시장의** 독립 레그 ≥ **12**
2. 부트스트랩 CI 반폭 ≤ **0.10**
3. 시장별 **별도 전사** — 빌린 테이블 절대 금지(`confidence_spec §5`)

**단조성은 판정 조건이 아니라 공시 대상이다.** 비단조 셀은 그대로 공개한다.
