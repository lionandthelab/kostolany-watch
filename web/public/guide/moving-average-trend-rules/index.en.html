Reading trend with moving averages: all eight rules this site uses

Updated 2026-08-04

A moving average is the mean of the last N closing prices. It erases day-to-day noise so that only direction remains. A 20-day line averages the last 20 sessions; a 200-day line covers roughly ten months.

Why compare price to its average

The oldest and simplest trend test asks whether price sits above or below its own average. Above means recent action is stronger than the past window; below means the opposite. Short averages react quickly but flip often; long ones are slow but steady. No single length is correct — each has a different character.

The eight rules this site uses

The default call is not a trained model. It is a majority vote of these eight rules, with zero fitted parameters:

  • close > 20-day moving average
  • close > 40-day moving average
  • close > 60-day moving average
  • close > 100-day moving average
  • close > 200-day moving average
  • 10-day return > 0
  • 20-day return > 0
  • 60-day return > 0

Count how many point up; a majority means an up leg. A four-four tie resolves to the up leg by a rule fixed in advance. Anyone can reproduce all of this in any charting app.

Why something this simple

Measured side by side under identical conditions, the unfitted trend rules beat the trained heads at telling an up leg from a down leg. Following a rule fixed in advance, the trained models were demoted to reference views and the rules became the default.

What moving averages cannot do

A moving average is a summary of prices already past, so it always lags. It does not announce turning points, and it whipsaws in range-bound markets. It organises direction; it does not reveal the future.
