Can AI predict stock prices? What we measured, and what we stopped claiming

Updated 2026-08-04

Plenty of services promise price prediction. This is a note from the other direction: we measured it, it did not work, and so we removed the claim.

How it was measured

The commonest trap in model evaluation is future information leaking into training. Evaluation here uses purged cross-validation with an embargo between train and test, an execution lag so a signal is acted on at the next bar rather than its own, and an auditor that flags lag violations automatically. Scoring happens only out of sample.

Finding 1 — the trained models lost to a simple rule

At telling an up leg from a down leg, moving-average rules with zero fitted parameters beat the trained heads. The tempting conclusion is that the model is weak. The actual cause was the missing comparator — nobody had run the obvious baseline.

Finding 2 — three-month direction skill was zero

Tested on direction 63 trading days ahead, the models did not clear a baseline that simply answers “up, always”. So the three-month path is drawn as a flat line with a stated band instead of an arrow, and any sentence that reads as a direction forecast is banned from the interface.

Finding 3 — some of it is structurally impossible

Pinning the exact box among six has an arithmetic ceiling. A box boundary is only fixed once the next turning point arrives, so position within a leg is close to chance for any model restricted to the past. That is a limit of the definition, not something a larger model fixes.

What is left

What remains is description, not prediction: whether the market is in an up leg or a down leg, and how often that call was right historically. Every number on screen is a walk-forward out-of-sample result, and unmeasured markets show no numbers at all.

It is a smaller claim. It is also a checkable one, which we judged to be worth more than an inflated forecast.
